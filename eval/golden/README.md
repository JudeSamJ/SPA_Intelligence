# Golden set

Each document lives in its own folder:

```
eval/golden/<doc_id>/
  doc.pdf        the contract (text PDF; scanned PDFs are not supported yet)
  labels.json    the truth, with page numbers
```

`labels.json` carries the same fields as `ContractData`, each with the **value**, the **page** (1-based) and a
verbatim **quote** from that page. `null` means "the document does not state it".

```json
{
  "doc_id": "my_doc",
  "kind": "real",            // "real" or "synthetic"
  "synthetic": false,
  "currency": "INR",
  "buyer":       {"value": "A. Buyer", "page": 1, "quote": "A. Buyer"},
  "unit_id":     {"value": "T2-1503", "page": 2, "quote": "Unit T2-1503"},
  "price":       {"value": 8450000, "page": 3, "quote": "INR 8,450,000"},
  "area_sqft":   {"value": 865.0, "page": 3, "quote": "865.00 sq ft"},
  "handover_date": {"value": "2026-12-31", "page": 4, "quote": "31 December 2026"},
  "grace_period_days": {"value": 90, "page": 4, "quote": "90 days"},
  "delay_rate":  {"value": 60.0, "page": 4, "quote": "INR 60.00 per square foot"},
  "delay_basis": {"value": "fixed_per_sqft_per_year", "page": 4, "quote": "INR 60.00 per square foot"},
  "delay_cap":   {"value": 3.0, "page": 4, "quote": "shall not exceed 3% of the Purchase Price"},
  "cancellation_clause": {"value": "present", "page": 5, "quote": "Buyer's right to cancel for delay"},
  "payment_plan": [
    {"name": "Booking", "percent": 10.0, "due_date": "2024-03-01", "trigger": "On signing", "page": 6, "quote": "Booking 10% 1 March 2024 On signing"}
  ]
}
```

Matching rules used by `eval/run_eval.py`: numbers and dates must match exactly; names/ids are compared after
whitespace/case normalisation; `cancellation_clause` is scored on presence (any non-null value means "present");
payment-plan rows match on (percent, due date).

## Labelling a real document

1. Put the PDF in a new folder as `doc.pdf` and set `"kind": "real"`, `"synthetic": false`.
2. Easiest start: upload it in the app, open the **Review queue**, accept/correct every flagged field, then call
   `POST /api/contracts/{id}/golden-export`. That writes `eval/golden/<doc_id>/` with the human-verified values.
3. Open `labels.json` and **read every field against the PDF yourself** (the export only contains what a human verified;
   fields still needing review are listed under `unverified_fields` and the export refuses unless you pass
   `allow_partial`). A label that was never checked by a person is not a label.
4. Run `python eval/run_eval.py --yes`.

## Adding public documents (manually)

Public regulator orders and similar documents can be added **by hand** after you have checked the source's terms of
use. This project deliberately contains **no scraper** for any government site. Keep the source URL and retrieval date in
`labels.json` under `"source"`. Redact personal data you are not allowed to keep.

## What this set can and cannot tell you

The four `synthetic_*` documents are a **smoke set**: generated by `scripts/generate_samples.py`, so their labels are
known by construction. Passing them shows the pipeline is wired correctly. It says **nothing** about accuracy on real
contracts, and no real-document accuracy is claimed anywhere until real documents are added here.
